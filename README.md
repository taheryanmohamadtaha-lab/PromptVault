# گنجینه پرامپت (PromptVault)

> تمام پرامپت‌های هوشمند شما، همیشه در دسترس و منظم

برنامه‌ی دسکتاپ ویندوز برای ذخیره، دسته‌بندی، جست‌وجو، ویرایش و استفاده‌ی دوباره‌ی پرامپت‌های هوش مصنوعی.
کاملاً فارسی و راست‌چین، کاملاً آفلاین؛ داده‌ها فقط روی کامپیوتر خودتان می‌مانند.

## امکانات

- **داشبورد** با کارت‌های آماری قابل‌کلیک، آخرین پرامپت‌ها، ستاره‌دارها و جست‌وجوی سریع
- **مدیریت پرامپت**: ثبت، ویرایش، تکثیر، انتقال، علاقه‌مندی، سنجاق، بایگانی، سطل بازیافت، شمارنده‌ی استفاده
- **ویرایشگر** با ذخیره‌ی خودکار، شمارش کلمه/کاراکتر، بزرگ‌نمایی، Markdown و چسباندن از Clipboard
- **دسته‌بندی درختی** با زیردسته، رنگ و آیکون
- **برچسب‌ها** و **جست‌وجوی فارسی/انگلیسی** با هایلایت و فیلترهای پیشرفته
- **تاریخچه‌ی نسخه‌ها**: مشاهده، مقایسه و بازیابی نسخه‌های قبلی
- **قالب‌های آماده** با متغیر `{{APP_NAME}}` و ساخت خودکار پرامپت نهایی
- **پیوست فایل** (PNG, JPG, PDF, TXT, MD, DOCX و ...)
- **مقایسه‌ی دو پرامپت** و **پرامپت‌های مشابه** (کاملاً محلی)
- **بکاپ و انتقال**: فرمت `.pvault`، خروجی JSON / CSV / Markdown / TXT، بکاپ خودکار، بازیابی با پیش‌نمایش و ادغام هوشمند
- **۸ تم** (روشن، تاریک، خودکار، آبی، بنفش، سبز، فیروزه‌ای، پرانرژی) + رنگ تأکیدی دلخواه
- **میانبرها**: `Ctrl+N` جدید، `Ctrl+F` جست‌وجو، `Ctrl+S` ذخیره، `Ctrl+E` ویرایش، `Ctrl+D` تکثیر، و جست‌وجوی سریع سراسری (پیش‌فرض `Ctrl+Shift+Space`)

## اجرا از سورس (برای توسعه‌دهندگان)

```bash
pip install -r requirements-dev.txt
python main.py
python -m pytest -q          # تست‌ها
```

## ساخت EXE

روی ویندوز: `scripts\build_windows.bat` را دوبار کلیک کنید، یا Workflow گیت‌هاب را اجرا کنید
(جزئیات در راهنمای انتشار). خروجی: `PromptVault.exe` مستقل، ZIP قابل‌حمل و (در صورت موفقیت) فایل Setup.

## ساختار

```
main.py                نقطه‌ی شروع (+ حالت --selftest برای CI)
app/core/              دیتابیس، تنظیمات، بکاپ، ورود و خروج داده
app/models/            مدل‌های داده
app/services/          منطق برنامه (پرامپت، جست‌وجو، نسخه، قالب، فایل)
app/ui/                رابط کاربری PySide6
app/themes/            تم‌ها و QSS
tests/                 تست‌های خودکار
installer/             اسکریپت Inno Setup
.github/workflows/     ساخت خودکار ویندوز
```
