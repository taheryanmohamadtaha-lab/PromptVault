# گزارش تست و کنترل کیفیت — نسخه 1.0.0

تاریخ: ۱۱ آبان ۱۴۰۵ (2026-11-02)

## خلاصه

| بخش | وضعیت | توضیح |
|---|---|---|
| تست‌های منطق برنامه (دیتابیس، سرویس‌ها، بکاپ، تم، میانبر) | ✅ **۶۱ مورد قبول** | اجرا شده در محیط توسعه |
| بررسی ایستای کد (خطاهای واقعی: متغیر تعریف‌نشده، import اضافی، باگ‌های رایج) | ✅ بدون خطا | `ruff --select F,E9,B,PLE` |
| تست‌های رابط گرافیکی (Smoke, 1 مورد) | ⏳ **در این محیط اجرا نشد** | محیط توسعه اجازه‌ی نصب PySide6 نداشت |
| خودآزمون EXE ساخته‌شده روی ویندوز | ⏳ **هنوز اجرا نشده** | در Workflow گیت‌هاب اجرا می‌شود |
| ساخت EXE / Setup | ⏳ **هنوز ساخته نشده** | نیاز به ویندوز؛ در Workflow گیت‌هاب |
| مخزن GitHub | ❌ ساخته نشد | حساب GitHub به Claude وصل نیست (راهنمای GITHUB-SETUP) |

> تا زمانی که Workflow یک‌بار روی ویندوز با موفقیت اجرا نشود، **اجرای واقعی رابط گرافیکی و فایل EXE تأیید نشده است.** این Workflow خودش تست رابط و خودآزمون EXE را اجرا می‌کند و در صورت شکست، ساخت را متوقف می‌کند.

## موارد آزمایش‌شده (خودکار)

مطابق فهرست بند ۱۹ مشخصات:

- ساخت / ویرایش / حذف به سطل / بازیابی / حذف دائمی پرامپت؛ رد عنوان خالی
- تکثیر، انتقال بین دسته‌ها، علاقه‌مندی، سنجاق، بایگانی، شمارنده‌ی استفاده
- دسته‌بندی درختی و زیردسته، حذف دسته با تعیین تکلیف پرامپت‌ها
- برچسب‌ها
- جست‌وجوی فارسی و انگلیسی و فیلترها؛ هایلایت امن
- نسخه‌ها (ذخیره‌ی نسخه‌ی قبلی، عدم سیل نسخه در ذخیره‌ی خودکار)
- قالب‌ها و جایگزینی متغیرها
- پیوست‌ها
- پرامپت‌های مشابه
- خروجی JSON، `.pvault`، CSV، Markdown/TXT
- **انتقال کامل به نصب تازه** (`test_full_transfer_to_fresh_install`)
- ادغام، شناسایی تکراری و احترام به تصمیم کاربر، حالت جایگزینی کامل
- ساخت خودکار بکاپ ایمنی قبل از بازیابی
- **بازیابی ناموفق هیچ چیز را تغییر نمی‌دهد** (`test_failed_import_changes_nothing`)
- امنیت: Zip Slip، فایل‌های اضافه در ZIP، پیمایش مسیر در داده، بکاپ خراب یا دستکاری‌شده، فرمت اشتباه، نسخه‌ی آینده، داده‌ی ناقص
- زمان‌بندی بکاپ خودکار، بکاپ هنگام خروج، چرخش و حذف بکاپ‌های قدیمی
- کپی امن از دیتابیس زنده
- کار بدون اینترنت
- همه‌ی ۸ تم، پیروی تم «خودکار» از ویندوز، رنگ تأکیدی، ماندگاری تم و تنظیمات پس از راه‌اندازی مجدد
- ماندگاری داده حتی بدون بستن عادی برنامه
- مسیر دلخواه داده
- ثبت و اعتبارسنجی میانبر سراسری

## تغییرات این دور

- آدرس پیش‌فرض بررسی به‌روزرسانی به یک مخزن نامرتبط اشاره می‌کرد؛ خالی شد و در صورت خالی بودن پیام راهنما نشان می‌دهد.
- افزودن README، راهنمای کاربر، راهنمای انتشار، راهنمای GitHub و همین گزارش.

## محدودیت‌های شناخته‌شده

- میانبر سراسری فقط روی ویندوز کار می‌کند.
- Setup بدون امضای دیجیتال است؛ ویندوز ممکن است هشدار SmartScreen بدهد.
- بررسی به‌روزرسانی فقط صفحه‌ی Releases را در مرورگر باز می‌کند (عمداً، برای حفظ حریم خصوصی).
- ساخت Setup (Inno Setup) اختیاری است و ممکن است جداگانه خطا بدهد؛ EXE و ZIP مستقل از آن ساخته می‌شوند.
