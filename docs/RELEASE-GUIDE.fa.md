# راهنمای نسخه‌سازی، انتشار و به‌روزرسانی

## ساخت خودکار (GitHub Actions)

فایل `.github/workflows/windows-build.yml` روی ویندوز این مراحل را انجام می‌دهد:

1. نصب Python 3.12 و وابستگی‌ها
2. اجرای همه‌ی تست‌ها (منطق + رابط کاربری، بدون نمایشگر)
3. ساخت `PromptVault.exe` با PyInstaller
4. **خودآزمون EXE**: خود فایل ساخته‌شده اجرا می‌شود، همه‌ی صفحه‌ها و تم‌ها را باز می‌کند و یک بکاپ سالم می‌سازد؛ در صورت شکست، ساخت متوقف می‌شود
5. ساخت ZIP قابل‌حمل
6. ساخت Setup با Inno Setup (اختیاری؛ اگر خطا بدهد، EXE و ZIP همچنان تحویل داده می‌شوند)
7. بارگذاری خروجی‌ها به‌عنوان Artifact، و برای Tag ها انتشار خودکار GitHub Release

## چگونه نسخه‌ی جدید منتشر کنم؟

1. شماره‌ی نسخه را در `app/__init__.py` تغییر دهید (مثلاً `1.1.0`).
2. روی GitHub: **Releases ‹ Draft a new release ‹ Choose a tag**، نام `v1.1.0` را بنویسید ← **Create new tag** ← **Publish**.
3. Workflow خودکار اجرا می‌شود و فایل‌ها به Release اضافه می‌شوند.

برای ساخت بدون انتشار: **Actions ‹ Windows Build ‹ Run workflow** (خروجی در Artifacts).

## ساخت روی کامپیوتر خودتان

Python 3.12 نصب کنید و `scripts\build_windows.bat` را دوبار کلیک کنید. خروجی: `dist\PromptVault\PromptVault.exe`.

## قواعد نسخه‌گذاری

`major.minor.patch`: رفع اشکال ← patch، قابلیت جدید ← minor، تغییر ناسازگار ← major.
فرمت `.pvault` نسخه‌دار است (`format_version`)؛ نسخه‌ی قدیمی برنامه، بکاپ ساخته‌شده با فرمت جدیدتر را با پیام فارسی رد می‌کند و چیزی را خراب نمی‌کند.

## به‌روزرسانی برای کاربر

Setup جدید را روی نسخه‌ی قبلی نصب کنید. داده‌ها در `AppData\Local\PromptVault\data` می‌مانند. پیش از به‌روزرسانی بکاپ بگیرید.
